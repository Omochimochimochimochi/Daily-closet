Daily Closet

アプリ概要

Daily Closetは、アパレル販売の経験をもとに開発した ファッションECアプリです。

骨格タイプ・パーソナルカラー・機能性などの ハッシュタグを組み合わせて、自分に合った服を検索できます。

商品の生地感や裏地、ポケットなどの画像も掲載し、 オンラインショッピングでの購入時のミスマッチ軽減を目指しました。

特徴

  • 複数のハッシュタグによるAND検索
  • 骨格タイプ・パーソナルカラーで商品検索
  • 商品ディテール画像の掲載
  • 商品登録・編集・公開設定ができる管理画面
